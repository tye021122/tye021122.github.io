# 1. 함수 호출과 값 전달

## 1.1 인수·매개변수와 호출자·피호출자

함수를 호출할 때는 **인수와 매개변수**를 구분해야 한다

|구분|의미|예시|
|---|---|---|
|**인수(Argument)**|함수를 호출할 때 전달하는 값이나 식|`swap_wrong(a, b)`의 `a`, `b`|
|**매개변수(Parameter)**|전달된 값을 받도록 함수에 선언한 변수|`void swap_wrong(int a, int b)`의 `a`, `b`|

- **호출자(Caller):** 다른 함수를 호출하는 함수
- **피호출자(Callee):** 호출되는 함수

예를 들어 `main()`에서 `swap_wrong()`을 호출하면, `main()`이 호출자이고 `swap_wrong()`이 피호출자이다


## 1.2 값 전달의 의미

> [!NOTE] 값 전달(Call-by-value)  
> 함수를 호출할 때 인수의 값으로 **별개의 매개변수를 초기화하는 방식**이다. 기본 자료형의 예제에서는 인수의 값이 매개변수에 복사된다고 이해할 수 있다

매개변수 자체에 다른 값을 대입해도 호출자의 변수는 바뀌지 않는다

```Cpp
void change(int num) {
    num = 100;
}

int main() {
    int value = 10;

    change(value);

    // value는 여전히 10
    return 0;
}
```

`change()`의 `num`과 `main()`의 `value`는 별개의 변수이기 때문이다

> [!NOTE] 포인터도 값으로 전달할 수 있음  
> 포인터를 값으로 전달하면 주소 값이 복사된다. 포인터 매개변수 자체를 변경해도 호출자의 포인터는 바뀌지 않지만, **복사된 포인터로 원본 객체에 접근하여 그 내용을 수정할 수 있다**


## 1.3 값 전달로 교환이 이루어지지 않는 예시

<figure> <img src="Pasted image 20260920222525.png" width="400"> <figcaption>그림 1. 값 전달을 이용한 교환 예시</figcaption> </figure>


본문 설명에 해당하는 예제는 다음과 같다

출력:
```
a = 10
b = 20
```

함수를 호출하면 다음과 같이 값이 복사된다

|변수|소속 함수|호출 직후 값|
|---|---|---|
|원본 `a`|`main()`|10|
|원본 `b`|`main()`|20|
|매개변수 `a`|`swap_wrong()`|10|
|매개변수 `b`|`swap_wrong()`|20|

이름이 같더라도 **서로 다른 함수에 속한 별개의 변수**이다

`swap_wrong()`에서 교환되는 것은 매개변수 `a`, `b`의 값뿐이다

|실행 단계|매개변수 `a`|매개변수 `b`|`temp`|
|---|---|---|---|
|함수 호출 직후|10|20|—|
|`int temp = a;`|10|20|10|
|`a = b;`|20|20|10|
|`b = temp;`|20|10|10|

함수가 종료되면 매개변수와 지역 변수 `temp`의 수명이 끝난다. `main()`의 원본 변수는 수정되지 않았으므로 그대로 남는다

**원본이 바뀌지 않는 이유**
- 값 전달로 생성한 복사본만 수정했다
- 원본 변수에 접근할 주소나 참조를 전달하지 않았다
- 따라서 이 함수의 코드는 호출자의 두 변수를 교환하지 못한다


## 1.4 함수 호출과 스택 프레임

> [!NOTE] 스택 프레임(Stack Frame)  
> 일반적인 구현에서 한 번의 함수 호출을 처리하는 데 필요한 정보를 모아 두는 스택 영역이다.

스택 프레임에는 일반적으로 다음 정보가 포함될 수 있다
- 함수의 매개변수
- 지역 변수
- 함수 종료 후 돌아갈 위치인 복귀 주소
- 그 밖의 호출 상태 정보

일반적인 스택 모델에서는 함수가 다른 함수를 호출하면 새로운 호출에 필요한 프레임이 추가되고, 함수가 반환하면 해당 프레임이 제거된다

앞선 예시에서 `swap_wrong()`의 매개변수와 `temp`는 해당 호출에 속한 지역 객체이다. 함수 호출이 끝나면 이 객체들의 수명도 끝난다

> [!NOTE] 개념적인 메모리 모델  
> 실제 구현에서는 매개변수나 지역 변수가 레지스터에 저장되거나, 함수가 인라인화되는 등 최적화가 적용될 수 있다. 스택 프레임 설명은 **변수의 수명과 함수 호출 관계를 이해하기 위한 전형적인 모델**이다

# 2. 포인터를 이용한 원본 변수 수정

## 2.1 주소 값의 전달

> [!NOTE] 포인터를 통한 원본 접근  
> 함수에 **원본 변수의 주소를 전달하고**, 함수 안에서 포인터를 역참조하여 원본의 값을 읽거나 수정하는 방식이다
- 주소 값이 포인터 매개변수에 복사된다
- 피호출 함수는 전달받은 주소를 통해 호출자의 변수에 접근한다
- 원본 객체를 직접 수정하므로 함수가 종료된 뒤에도 변경 결과가 유지된다

이 방식에서도 포인터 매개변수 자체는 별개의 변수이다. 공유되는 것은 포인터 변수가 아니라 **그 포인터가 가리키는 원본 객체**이다


## 2.2 포인터를 이용한 값 교환

<figure> <img src="Pasted image 20260920222635.png" width="400"> <figcaption>그림 2. 포인터를 이용한 교환 예시</figcaption> </figure>

출력:
```
a = 20
b = 10
```

호출할 때 정수 값 `a`, `b`가 아니라 **주소인 `&a`, `&b`를 전달**한다

함수 안에서는 전달받은 포인터를 역참조하여 원본 값을 교환한다


## 2.3 원본 변수와 포인터 매개변수

같은 이름을 사용하더라도 두 함수의 변수는 구분해야 한다

|표현|소속|자료형|의미|
|---|---|---|---|
|`a`|`main()`|`int`|원본 정수 변수|
|`b`|`main()`|`int`|원본 정수 변수|
|`a`|`swap()`|`int*`|`main()`의 `a` 주소를 저장하는 포인터|
|`b`|`swap()`|`int*`|`main()`의 `b` 주소를 저장하는 포인터|
|`*a`|`swap()`|`int`인 객체에 접근|`main()`의 `a`에 접근|
|`*b`|`swap()`|`int`인 객체에 접근|`main()`의 `b`에 접근|

**포인터 매개변수의 값은 주소이고, 역참조한 대상은 원본 정수 변수**이다


## 2.4 단계별 실행 과정

**첫 번째 원본 값 보관**
```Cpp
int temp = *a;
```

포인터 `a`가 가리키는 원본 값 10을 `temp`에 복사한다

**첫 번째 원본 값 변경**
```Cpp
*a = *b;
```

두 번째 원본 값 20을 첫 번째 원본 변수에 저장한다

**두 번째 원본 값 변경**
```Cpp
*b = temp;
```

보관했던 값 10을 두 번째 원본 변수에 저장한다

|실행 단계|`main()`의 `a`|`main()`의 `b`|`temp`|
|---|---|---|---|
|함수 호출 직후|10|20|—|
|`int temp = *a;`|10|20|10|
|`*a = *b;`|20|20|10|
|`*b = temp;`|20|10|10|

함수가 종료되어 포인터 매개변수와 `temp`의 수명이 끝나더라도, **원본 변수의 변경 결과는 유지**된다

> [!WARNING] 유효한 주소 전달  
> 이 함수는 두 포인터가 접근 가능한 정수 객체를 가리킨다고 가정한다. 널 포인터나 수명이 끝난 객체의 주소를 전달하여 역참조해서는 안 된다.


## 2.5 정수 값 전달과 비교

|구분|정수 값 전달|포인터를 통한 주소 전달|
|---|---|---|
|함수 선언|`void swap_wrong(int a, int b)`|`void swap(int* a, int* b)`|
|호출|`swap_wrong(a, b)`|`swap(&a, &b)`|
|복사되는 값|정수 값|주소 값|
|함수 안의 수정 대상|매개변수인 복사본|역참조로 접근한 원본|
|호출자의 값 교환|이루어지지 않음|이루어짐|

두 방식 모두 값을 전달하지만, **전달하는 값이 정수인지 주소인지**, 그리고 **수정하는 대상이 매개변수인지 원본 객체인지**가 다르다


## 2.6 C++ 참조 매개변수와의 구분

> [!NOTE] 슬라이드의 Call-by-reference 표현  
> 슬라이드에서는 포인터로 주소를 전달하는 방식을 참조 전달이라고 부르지만, 엄밀히는 **포인터를 값으로 전달하여 원본에 간접 접근하는 방식**이다. C++의 참조 매개변수인 `int&`를 사용하는 방식과 구분해야 한다

C++ 참조 매개변수로 작성하면 다음과 같다

```Cpp
void swap_ref(int& a, int& b) {
    int temp = a;
    a = b;
    b = temp;
}
```

호출할 때는 변수 자체를 인수로 작성한다

```Cpp
swap_ref(a, b);
```

|구분|포인터 매개변수|참조 매개변수|
|---|---|---|
|선언|`int* a`|`int& a`|
|호출 예시|`swap(&a, &b)`|`swap_ref(a, b)`|
|원본 접근|`*a`처럼 역참조|`a`로 직접 사용|

# 3. 함수에 배열과 문자열 전달하기
## 3.1 정수 배열 전달

> [!NOTE] 배열을 포인터 매개변수에 전달  
> 기본 배열을 포인터 매개변수에 전달하면 **배열 전체가 복사되는 것이 아니라 첫 번째 원소를 가리키는 포인터 값이 전달**된다
- 함수는 포인터를 통해 원본 배열의 원소에 접근한다
- 포인터만으로는 원소 개수를 알 수 없으므로, 일반적으로 길이도 함께 전달한다


### 3.1.1 배열 출력 예시
```Cpp
#include <cstdio>

void printArray(int* arr, int len) {
    for (int i = 0; i < len; ++i) {
        std::printf("%d ", arr[i]);
    }

    std::printf("\n");
}

int main() {
    int arr[] = {5, 10, 15, 1};

    printArray(arr, 4);

    return 0;
}
```

출력:
```
5 10 15 1
```


### 3.1.2 전달되는 정보와 매개변수의 자료형
```Cpp
printArray(arr, 4);
```

|인수|전달되는 내용|매개변수|
|---|---|---|
|`arr`|첫 번째 원소의 주소인 `&arr[0]`|`int* arr`|
|`4`|배열의 원소 개수|`int len`|

`main()`의 `arr`는 **정수 배열**이고, `printArray()`의 `arr`는 **포인터 매개변수**이다

다음 두 함수 선언은 같은 매개변수 자료형을 나타낸다

```Cpp
void printArray(int arr[], int len);
void printArray(int* arr, int len);
```

함수 매개변수에서 `int arr[]`처럼 작성해도 배열 전체를 받는 것이 아니다. 해당 매개변수의 자료형은 `int*`로 조정된다


### 3.1.3 포인터의 인덱스 접근
내장 인덱스 연산에서 다음 두 표현은 같은 원소에 접근한다

```Cpp
arr[i]
*(arr + i)
```
- `arr + i`: 첫 번째 원소에서 `i`개 원소만큼 이동한 위치
- `*(arr + i)`: 그 위치의 원소에 접근

따라서 매개변수가 포인터여도 배열처럼 `arr[i]`로 원소에 접근할 수 있다

포인터 연산에는 원소 크기가 자동으로 반영되므로, `arr + 1`은 다음 정수 원소를 가리킨다


### 3.1.4 배열 길이와 `sizeof`
함수 안에서 다음 코드를 사용해도 원본 배열 전체 크기는 얻을 수 없다

```Cpp
sizeof(arr)  // printArray() 안에서는 포인터 자체의 크기
```

반면 실제 배열이 선언된 위치에서는 배열 전체 크기를 구할 수 있다

```Cpp
int arr[] = {5, 10, 15, 1};

sizeof(arr)                   // 배열 전체 크기
sizeof(arr) / sizeof(arr[0])   // 원소 개수인 4
```

함수는 전달받은 `len`을 이용해 접근 범위를 결정한다

> [!WARNING] 실제 크기와 전달한 길이  
> 전달한 길이는 실제로 접근 가능한 원소 수를 넘지 않아야 한다. 포인터 매개변수만으로 실제 배열 크기를 검증할 수 있는 것은 아니다.


### 3.1.5 `const`를 이용한 수정 제한
출력만 하는 함수라면 다음처럼 선언할 수 있다

```Cpp
void printArray(const int* arr, int len);
```

이렇게 하면 함수 안에서 **해당 포인터를 통한 원소 변경**을 방지한다

```Cpp
void printArray(const int* arr, int len) {
    arr[0] = 100;  // 컴파일 오류

    for (int i = 0; i < len; ++i) {
        std::printf("%d ", arr[i]);
    }

    std::printf("\n");
}
```


## 3.2 C 스타일 문자열 전달

### 3.2.1 문자 배열의 시작 주소 전달
```Cpp
#include <cstdio>

void print(char* a) {
    std::printf("%s %c\n", a, a[1]);
}

int main() {
    char str[] = "Hello";

    print(str);

    return 0;
}
```
- `str`는 널 문자를 포함한 **6개 원소의 문자 배열**이다
- `print(str)`를 호출하면 첫 번째 문자인 `'H'`의 주소가 전달된다
- 매개변수 `a`는 원본 배열의 첫 번째 원소를 가리킨다

### 3.2.2 문자열 전체와 개별 문자 출력
```
std::printf("%s %c\n", a, a[1]);
```

|표현|의미|출력|
|---|---|---|
|`%s`에 전달한 `a`|해당 주소부터 널 문자 직전까지 출력|`Hello`|
|`%c`에 전달한 `a[1]`|인덱스 1의 문자 출력|`e`|

출력 결과:
```
Hello e
```

### 3.2.3 널 종료와 접근 범위
이 예시에서 `%s`는 **널 문자 `'\0'`를 만날 때까지 읽는 방식**으로 문자열의 끝을 찾는다
- 일반적인 정수 배열에는 끝을 나타내는 특별한 값이 없으므로 원소 개수가 필요하다
- C 스타일 문자열은 널 문자를 종료 표시로 사용한다
- 올바르게 널 종료되지 않았다면 배열 밖까지 읽을 수 있다
- `a[1]`처럼 개별 원소에 접근할 때도 해당 위치가 유효해야 한다

출력만 한다면 다음처럼 `const`를 붙이는 것이 적절하다

```Cpp
void print(const char* a) {
    std::printf("%s %c\n", a, a[1]);
}
```

이 선언은 수정 가능한 문자 배열뿐 아니라 문자열 리터럴도 전달받을 수 있다

```Cpp
char str[] = "Hello";

print(str);
print("Hello");
```

다만 두 경우 모두 함수에서 사용하는 `a[1]`에 접근할 수 있어야 하며, `%s`로 읽을 문자열도 유효해야 한다


## 3.3 문자열 포인터 배열 전달

### 3.3.1 포인터 배열과 널 포인터
```Cpp
const char* str[3] = {"Hello", "HELLO"};
```

> [!NOTE] 포인터 배열  
> **각 원소가 포인터인 배열**이다. 위의 `str`는 문자를 가리키는 포인터 3개로 구성된다.

|원소|저장된 값|
|---|---|
|`str[0]`|`"Hello"`의 첫 번째 문자 주소|
|`str[1]`|`"HELLO"`의 첫 번째 문자 주소|
|`str[2]`|널 포인터|

크기는 3인데 초기값을 2개만 지정했으므로, 나머지 포인터 원소는 **널 포인터로 초기화**된다. 널 포인터와 널 문자는 서로 다르다

|구분|의미|
|---|---|
|널 포인터|객체나 함수를 가리키지 않는 포인터 값|
|널 문자 `'\0'`|값이 0인 문자이며 C 스타일 문자열의 종료 표시|

### 3.3.2 이중 포인터 매개변수
`str`의 각 원소는 `const char*`형이다. 함수에 `str`를 전달하면 **첫 번째 포인터 원소를 가리키는 포인터**로 변환된다

|표현|자료형 또는 의미|
|---|---|
|`str` 자체의 자료형|`const char*[3]`|
|`str[0]`의 자료형|`const char*`|
|`&str[0]`의 자료형|`const char**`|
|전달되는 값|첫 번째 포인터 원소의 주소|

따라서 매개변수는 다음처럼 선언할 수 있다

```Cpp
void print(const char** a);
```

### 3.3.3 전체 예시와 단계별 접근
```Cpp
#include <cstdio>

void print(const char** a) {
    std::printf("%s %s\n", a[0], a[1]);
}

int main() {
    const char* str[3] = {"Hello", "HELLO"};

    print(str);

    return 0;
}
```

출력:
```
Hello HELLO
```

|표현|의미|예시 결과|
|---|---|---|
|`a`|포인터 배열의 첫 원소를 가리킴|`&str[0]`|
|`a[0]`|첫 번째 문자열의 시작 주소|`"Hello"`를 가리킴|
|`a[1]`|두 번째 문자열의 시작 주소|`"HELLO"`를 가리킴|
|`a[0][0]`|첫 번째 문자열의 첫 문자|`'H'`|
|`a[0][1]`|첫 번째 문자열의 두 번째 문자|`'e'`|
|`a[1][1]`|두 번째 문자열의 두 번째 문자|`'E'`|

**첫 번째 인덱스는 문자열을 선택하고, 두 번째 인덱스는 해당 문자열 안의 문자를 선택**한다

> [!NOTE] 슬라이드 코드 수정  
> `char* str[3] = {"Hello", "HELLO"};`는 문자열 리터럴의 주소를 수정 가능한 문자 포인터로 받는 선언이다.
> 
> 현대 C++에서는 `const char* str[3]`로 바꾸고, 함수 매개변수도 이에 맞게 `const char**`로 작성한다.

`const char**`는 문자를 수정하지 못하게 하지만, 포인터 배열의 원소 변경까지 막지는 않는다

```Cpp
void change(const char** a) {
    a[0] = "Other";  // 가능: 첫 번째 포인터 원소 변경
    a[0][0] = 'o';  // 컴파일 오류: const 문자 수정
}
```

출력 함수에서 포인터 원소 변경까지 막고 싶다면 다음처럼 선언할 수 있다

```Cpp
void print(const char* const* a) {
    std::printf("%s %s\n", a[0], a[1]);
}
```

### 3.3.4 문자열 개수의 전달과 종료 표시
앞의 함수는 두 문자열을 출력하도록 고정되어 있다. 임의 개수의 문자열을 처리하려면 다음 중 하나의 규칙이 필요하다
- 포인터 배열의 원소 개수를 함께 전달한다
- 널 포인터를 배열의 끝 표시로 사용한다

현재 배열에서는 `str[2]`가 널 포인터이므로 끝 표시로 사용할 수 있다. 다만 함수가 그 규칙에 맞게 작성되어 있어야 한다

> [!WARNING] 널 포인터를 `%s`에 전달하지 않기  
> `str[2]`는 유효한 문자열을 가리키지 않으므로 `%s`의 인수로 전달해서는 안 된다. 일부 환경에서 특정 문구가 출력되더라도 그 동작에 의존하면 안 된다

# 4. C++ 문자열 `std::string`

> [!NOTE] `std::string`  
> C++ 표준 라이브러리에서 제공하는 **문자열 클래스**이다. 문자열의 저장 공간을 관리하며 복사, 대입, 연결, 비교, 검색 등의 기능을 제공한다

사용하려면 `<string>` 헤더를 포함한다. `std::cout`도 사용한다면 `<iostream>`이 필요하다

```Cpp
#include <iostream>
#include <string>

int main() {
    std::string str = "hello world";

    std::cout << str << '\n';

    return 0;
}
```

출력:
```
hello world
```
- C 스타일 문자 배열처럼 저장 크기를 선언 시 고정하지 않아도 된다
- 문자열의 길이가 바뀌면 필요한 저장 공간을 관리한다
- `std::cout`으로 문자열 내용을 출력할 수 있다


## 4.1 선언과 초기화

```Cpp
char charr1[20];
char charr2[20] = "jaguar";

std::string str1;
std::string str2 = "panther";
```

|선언|의미|
|---|---|
|`char charr1[20];`|`char` 원소 20개를 저장할 배열 선언|
|`char charr2[20] = "jaguar";`|문자 배열을 `"jaguar"`로 초기화|
|`std::string str1;`|길이가 0인 빈 문자열 객체 생성|
|`std::string str2 = "panther";`|문자열 객체를 `"panther"`로 초기화|

> [!NOTE] 초기화하지 않은 문자 배열과 빈 문자열  
> 함수 안의 일반적인 지역 배열인 `char charr1[20];`은 빈 문자열로 초기화되지 않는다. 반면 `std::string str1;`은 **정상적인 빈 문자열**이다


## 4.2 대입·복사와 독립성

### 4.2.1 문자열 대입
C 스타일 배열은 배열 전체를 직접 대입할 수 없지만, `std::string`은 가능하다

```Cpp
charr1 = charr2;  // 컴파일 오류
str1 = str2;        // 가능
```

`str1 = str2;`를 실행하면 `str1`의 내용이 `"panther"`가 된다

### 4.2.2 문자열 복사와 독립성
```Cpp
#include <iostream>
#include <string>

int main() {
    std::string str1 = "hello";
    std::string str2 = str1;

    str1[0] = 'y';

    std::cout << str1 << '\n';
    std::cout << str2 << '\n';

    return 0;
}
```

출력:
```
yello
hello
```
- `str2`는 `str1`의 문자열 값을 복사하여 생성된다
- 이후 `str1`을 수정해도 **`str2`의 내용은 바뀌지 않는다**
- 두 객체가 같은 문자열 변수의 별명이 되는 것은 아니다


## 4.3 문자열 연결: `+`, `+=`

|연산|의미|
|---|---|
|`a + b`|두 문자열을 연결한 결과를 생성|
|`a += b`|기존 문자열 `a` 뒤에 `b`를 추가|

```Cpp
std::string str = "hello world";
std::string str1 = str + " - bye world";
```

`str1`의 내용:
```
hello world - bye world
```

이때 원래 `str`의 내용은 그대로 유지된다

> [!NOTE] 문자열 리터럴끼리의 `+`  
> 위 예시는 한쪽 피연산자가 `std::string`이므로 가능하다. `"Hello" + "World"`처럼 문자열 리터럴 두 개에 직접 `+`를 사용하는 것은 불가능하다

### 4.3.1 문자열을 순서대로 추가하는 예시
```Cpp
std::string t1 = "I ";
std::string t2 = "Brian";

std::cout << t1.size() << '\n';

t1 += "love";
t1 += " ";
t1 += t2;

std::cout << t1.size() << '\n';
std::cout << t1 << '\n';
std::cout << t2 << '\n';
```

|실행 단계|`t1`의 내용|길이|
|---|---|---|
|초기화|`"I "`|2|
|`t1 += "love";`|`"I love"`|6|
|`t1 += " ";`|`"I love "`|7|
|`t1 += t2;`|`"I love Brian"`|12|

출력:
```
2
12
I love Brian
Brian
```

**공백도 문자열의 길이에 포함**된다


## 4.4 길이 확인: `size()`, `length()`

```
std::string str = "hello world";

std::cout << str.size() << '\n';    // 11
std::cout << str.length() << '\n';  // 11
```
- `size()`와 `length()`는 같은 의미이다
- 문자열에 저장된 **`char` 원소의 개수**를 반환한다
- 문자열 내부에 저장된 널 문자도 원소 수에 포함한다
- 문자열 끝에 별도로 제공되는 종료용 널 문자는 길이에 포함하지 않는다

> [!NOTE] 화면에 보이는 글자 수와 문자열 길이  
> `std::string`의 길이는 화면에 보이는 글자 수와 항상 같지는 않다. UTF-8처럼 한 글자를 여러 바이트로 표현하면 `size()`는 해당 바이트 수에 해당하는 `char` 원소 개수를 반환한다


## 4.5 개별 문자 접근과 수정

```Cpp
std::string str = "hello world";

std::cout << str[0] << '\n';  // h

str[0] = 'j';
```

변경 결과:
```
jello world
```
- 인덱스는 0부터 시작한다
- 문자열 내용에 해당하는 원소의 인덱스는 **0부터 `size() - 1`까지**이다
- 빈 문자열에는 이 범위의 원소가 없다
- `[]`는 범위를 자동으로 검사하여 예외를 발생시키는 접근 방식이 아니므로, 사용할 인덱스가 유효한지 확인해야 한다


## 4.6 크기 변경: `resize()`

```Cpp
std::string str = "jello world";
str.resize(5);
```

길이를 5로 줄이면 뒤쪽 문자가 제거된다

```
jello
```

| 사용 방식            | 동작                  |
| ---------------- | ------------------- |
| 현재보다 작은 크기 지정    | 뒤쪽 문자를 제거           |
| 현재와 같은 크기 지정     | 내용 변화 없음            |
| 현재보다 큰 크기 지정     | 기본적으로 `'\0'`를 추가    |
| `resize(크기, 문자)` | 크기를 늘릴 때 지정한 문자를 추가 |

```Cpp
std::string word = "Hi";
word.resize(5, '!');  // "Hi!!!"
```

추가할 문자를 지정하지 않으면 널 문자가 들어간다

```Cpp
std::string word = "Hi";
word.resize(5);
```

| 인덱스 | 0     | 1     | 2      | 3      | 4      |
| --- | ----- | ----- | ------ | ------ | ------ |
| 값   | `'H'` | `'i'` | `'\0'` | `'\0'` | `'\0'` |

이때 `word.size()`는 **5**이다. `std::string`은 내부의 널 문자도 문자열 원소로 저장할 수 있기 때문이다


## 4.7 문자열 비교

`std::string`은 다음 연산자로 **문자열 내용을 비교**할 수 있다

```
==  !=  <  <=  >  >=
```

|연산|의미|
|---|---|
|`a == b`|내용이 같음|
|`a != b`|내용이 다름|
|`a < b`|사전식 순서에서 `a`가 앞섬|
|`a <= b`|`a`가 앞서거나 내용이 같음|
|`a > b`|사전식 순서에서 `a`가 뒤에 옴|
|`a >= b`|`a`가 뒤에 오거나 내용이 같음|

사전식 비교는 앞에서부터 문자를 비교하여 **처음으로 다른 문자의 순서**로 판단한다. 한 문자열이 다른 문자열의 접두사이면 더 짧은 문자열이 앞선다

```Cpp
std::string a = "apple";
std::string b = "banana";

bool result = a < b;  // 일반적인 문자 인코딩에서 true
```

문자열을 숫자로 해석하여 비교하는 것은 아니다

```Cpp
std::string a = "10";
std::string b = "2";

bool result = a < b;  // true: 첫 문자 '1'이 '2'보다 앞섬
```

문자열 비교는 문자 코드 단위의 순서에 기반하며, 언어별 사전 정렬 규칙을 자동으로 적용하는 기능은 아니다


## 4.8 C 스타일 문자열 접근: `c_str()`

> [!NOTE] `c_str()`  
> `std::string`의 내용을 널 종료된 C 스타일 문자열로 읽을 수 있도록 **`const char*` 포인터를 반환하는 멤버 함수**이다

```Cpp
std::string str = "jello";
const char* ptr = str.c_str();

std::printf("%s\n", ptr);
```

출력:
```
jello
```

`printf()`의 `%s`는 `std::string` 객체가 아니라 **C 스타일 문자열의 주소**를 받는다

```Cpp
std::printf("%s\n", str.c_str());  // 올바른 사용
```

### 4.8.1 반환된 포인터의 수명
- `c_str()`는 독립된 문자열 복사본을 만드는 함수가 아니다
- 반환된 포인터로 내용을 수정해서는 안 된다
- 원본 문자열이 소멸하면 해당 포인터를 사용할 수 없다
- 문자열을 변경하는 연산으로 포인터가 무효화될 수도 있다
- 문자열 변경 후에는 필요하면 `c_str()`를 다시 호출한다

### 4.8.2 문자열 내부의 널 문자
```Cpp
std::string word = "Hi";
word.resize(5);

std::cout << word.size() << '\n';
std::printf("%s\n", word.c_str());
```

출력:
```
5
Hi
```

`std::string`의 길이는 5이지만, `%s`는 첫 널 문자에서 멈추므로 `Hi`만 출력한다

**`std::string`이 관리하는 길이와 C 스타일 문자열로 읽을 때의 종료 위치는 다를 수 있다**


## 4.9 기본 기능 종합 예제

```Cpp
#include <cstdio>
#include <iostream>
#include <string>

int main() {
    std::string str = "hello world";
    std::cout << str << '\n';

    std::string str1 = str + " - bye world";
    std::cout << str1 << '\n';
    std::cout << str1.length() << '\n';
    std::cout << str1[0] << '\n';

    str[0] = 'j';
    str.resize(5);
    std::cout << str << '\n';

    const char* ptr = str.c_str();
    std::printf("%s\n", ptr);

    return 0;
}
```

출력:
```
hello world
hello world - bye world
23
h
jello
jello
```

`"hello world"`는 11개, `" - bye world"`는 12개의 `char` 원소로 이루어져 있으므로, 연결한 문자열의 길이는 **23**이다

# 5. 문자열 검색, 추출, 변경

|함수|기능|
|---|---|
|`find()`|문자나 문자열을 찾아 시작 인덱스 반환|
|`substr()`|문자열의 일부를 새 문자열로 반환|
|`replace()`|지정한 구간을 다른 문자열로 교체|
|`insert()`|지정한 위치에 문자열 삽입|

다음 문자열을 기준으로 설명한다

```Cpp
std::string sentence = "I like an apple, an orange, and an kiwi";
```

아래 예제는 이 문자열에서 시작하며, `replace()`와 `insert()`는 순서대로 이어서 실행한다

> [!NOTE] 원본 예문의 표현  
> 인덱스와 실행 결과를 원본 슬라이드와 비교할 수 있도록 문자열을 유지했다. 영어 문법상 마지막의 `"an kiwi"`는 `"a kiwi"`가 적절하다


## 5.1 검색: `find()`

기본 형태:
```
문자열.find(찾을_내용);
문자열.find(찾을_내용, 검색_시작_위치);
```

### 5.1.1 첫 번째 일치 위치
```Cpp
auto first = sentence.find("an");
```

결과는 **7**이다. `find()`는 일치하는 부분의 **시작 인덱스**를 반환한다.

### 5.1.2 다음 일치 위치
```Cpp
sentence.find("an", first + 1);
```

현재 예시에서는 `first`가 7이므로 인덱스 8부터 검색한다. 다음 `"an"`의 시작 위치인 **17**을 반환한다

일반적인 코드에서는 첫 검색의 성공 여부를 확인해야 한다
```Cpp
auto first = sentence.find("an");

if (first != std::string::npos) {
    auto second = sentence.find("an", first + 1);

    if (second != std::string::npos) {
        std::cout << second << '\n';
    }
}
```

> [!NOTE] 단어가 아닌 문자 패턴 검색  
> `find("an")`은 독립된 단어만 찾는 것이 아니다. 검색을 계속하면 `"orange"`나 `"and"`에 포함된 `"an"`도 찾을 수 있다.

### 5.1.3 문자 검색
```Cpp
sentence.find('l');
```

`"like"`의 첫 문자인 `'l'`의 위치 **2**를 반환한다

### 5.1.4 검색 실패와 `npos`
> [!NOTE] `std::string::npos`  
> `find()`가 일치하는 내용을 찾지 못했을 때 반환하는 특별한 값이다

```Cpp
auto pos = sentence.find("banana");

if (pos == std::string::npos) {
    std::cout << "찾을 수 없음\n";
}
```

반환형을 유지하려면 `int`보다 다음 선언이 적절하다

```Cpp
auto pos = sentence.find("an");
```

또는:
```Cpp
std::string::size_type pos = sentence.find("an");
```

`npos`를 정상적인 인덱스로 사용하거나, 검색 성공을 확인하지 않고 다음 위치를 계산하지 않도록 주의한다


## 5.2 부분 문자열 추출: `substr()`

```
문자열.substr(시작_위치, 개수);
문자열.substr(시작_위치);
```

|코드|결과|
|---|---|
|`sentence.substr(2, 3)`|`"lik"`|
|`sentence.substr(2)`|`"like an apple, an orange, and an kiwi"`|

- 두 번째 인수는 **끝 인덱스가 아니라 추출할 원소 개수**이다
- 개수를 생략하면 해당 위치부터 끝까지 추출한다
- 새로운 문자열을 반환하며, **원본 문자열은 바뀌지 않는다**
- 지정한 개수가 남은 길이보다 크면 가능한 끝까지만 추출한다
- 시작 위치가 문자열 길이를 넘으면 예외가 발생한다


## 5.3 구간 교체: `replace()`

```
문자열.replace(시작_위치, 제거할_개수, 새_문자열);
```

```Cpp
sentence.replace(2, 4, "hate");
```

인덱스 2부터 4개 문자인 `"like"`를 `"hate"`로 교체한다

결과:
```
I hate an apple, an orange, and an kiwi
```

`replace()`는 **원본 문자열을 변경**한다. 제거하는 문자 수와 새로 넣는 문자열 길이는 같지 않아도 된다


## 5.4 문자열 삽입: `insert()`

```
문자열.insert(삽입_위치, 추가할_문자열);
```

앞의 교체 결과에 이어서 실행한다

```Cpp
sentence.insert(2, "don't ");
```

현재 인덱스 2에 있는 `'h'` 앞에 `"don't "`를 삽입한다

결과:
```
I don't hate an apple, an orange, and an kiwi
```

기존 문자는 제거하지 않고, 삽입한 문자열 뒤로 이동한다


## 5.5 전체 실행 예제와 결과

```Cpp
#include <iostream>
#include <string>

int main() {
    std::string sentence =
        "I like an apple, an orange, and an kiwi";

    auto first = sentence.find("an");

    // 이 고정된 예문에는 "an"이 존재한다.
    std::cout << first << '\n';
    std::cout << sentence.find("an", first + 1) << '\n';
    std::cout << sentence.find('l') << '\n';
    std::cout << sentence.substr(2, 3) << '\n';
    std::cout << sentence.substr(2) << '\n';

    sentence.replace(2, 4, "hate");
    std::cout << sentence << '\n';

    sentence.insert(2, "don't ");
    std::cout << sentence << '\n';

    return 0;
}
```

출력:
```
7
17
2
lik
like an apple, an orange, and an kiwi
I hate an apple, an orange, and an kiwi
I don't hate an apple, an orange, and an kiwi
```

# 6. C와 C++의 기본 입출력

## 6.1 C 스타일 입출력: `printf()`, `scanf()`

C 스타일 입출력에서는 `printf()`와 `scanf()`를 사용한다

```Cpp
#include <stdio.h>

int main(void) {
    int num;

    if (scanf("%d", &num) != 1) {
        return 1;
    }

    printf("hello %d\n", num);

    return 0;
}
```
- `scanf()`는 입력값을 저장할 **변수의 주소**를 받는다
- `%d`는 `int`형 정수를 입력받거나 출력하는 형식 지정자이다
- 위 코드에서 `scanf()`의 반환값이 1이면 정수 하나를 정상적으로 읽어 저장한 것이다
- `printf()`는 형식 지정자에 맞춰 전달된 값을 출력한다

C++에서도 C 스타일 입출력을 사용할 수 있다

```Cpp
#include <cstdio>

// std::printf(), std::scanf() 사용
```


## 6.2 스트림과 표준 입출력: `cin`, `cout`

> [!NOTE] 스트림(Stream)  
> 프로그램 안팎으로 전달되는 연속적인 데이터의 흐름을 다루는 입출력 개념이다

C++에서는 `<iostream>`의 `std::cin`, `std::cout`을 사용한다

|이름|의미|일반적인 연결 대상|
|---|---|---|
|`std::cin`|표준 입력 스트림|키보드|
|`std::cout`|표준 출력 스트림|화면|

입출력 재지정을 사용하면 파일 등 다른 대상으로 연결될 수도 있다

```Cpp
#include <iostream>

int main() {
    int num;

    if (!(std::cin >> num)) {
        return 1;
    }

    std::cout << "hello " << num << '\n';

    return 0;
}
```

위 코드는 정수 입력이 성공했을 때만 값을 출력한다


## 6.3 추출 연산자 `>>`와 삽입 연산자 `<<`

### 6.3.1 추출 연산자 `>>`
입력 스트림에서 값을 읽어 변수에 저장한다

```Cpp
std::cin >> num;
```

기본 형태:
```
입력스트림 >> 변수;
```

### 6.3.2 삽입 연산자 `<<`
출력 스트림에 값이나 문자열을 보낸다

```Cpp
std::cout << "num: " << num;
```

기본 형태:
```
출력스트림 << 값;
```

정수끼리 사용하는 `<<`, `>>`는 비트 이동 연산자이지만, 여기서는 스트림과 함께 사용하는 **입출력 연산자**이다


## 6.4 여러 값의 연속 입력과 출력

```Cpp
int s2;
int i;
double d;

if (std::cin >> s2 >> i >> d) {
    std::cout << "s2:" << s2
              << ", i:" << i
              << ", d:" << d
              << '\n';
}
```

입력 예시:
```
10 20 3.5
```

출력:
```
s2:10, i:20, d:3.5
```

- 기본적인 숫자 입력에서는 공백·탭·줄바꿈으로 값을 구분할 수 있다
- 입력값을 여러 줄에 나누어 제공해도 된다
- 일반적인 대화형 터미널에서는 Enter를 눌러 입력을 전달한다
- 필요한 입력이 아직 없으면 기다릴 수 있다
- 잘못된 형식이나 입력 종료를 만나면 입력에 실패할 수 있다
- 입력 성공 여부를 확인한 뒤 변수의 값을 사용하는 것이 좋다


## 6.5 줄바꿈과 플러시: `std::endl`과 `'\n'`

```Cpp
std::cout << std::endl;
```

`std::endl`은 다음 두 동작을 수행한다
1. 줄바꿈 문자 `'\n'`을 출력한다
2. 출력 버퍼의 데이터를 내보내는 **플러시(Flush)를** 수행한다

줄바꿈만 필요하면 다음처럼 작성할 수 있다

```Cpp
std::cout << '\n';
```

|표현|줄바꿈|명시적인 플러시|
|---|---|---|
|`'\n'`|수행|자체적으로 요청하지 않음|
|`std::endl`|수행|요청함|

`std::endl`을 자주 사용하면 불필요한 플러시가 반복될 수 있으므로, 단순 줄바꿈에는 `'\n'`을 사용할 수 있다


## 6.6 C 스타일과 C++ 스타일 비교

|구분|C 스타일|C++ 스타일|
|---|---|---|
|대표 헤더|`<stdio.h>`|`<iostream>`|
|입력|`scanf("%d", &num);`|`std::cin >> num;`|
|출력|`printf("%d", num);`|`std::cout << num;`|
|출력 형식 지정|형식 지정자 사용|값의 자료형에 맞는 연산 사용|
|입력 대상 지정|변수의 주소 전달|변수에 대한 입력 연산 사용|

두 방식 모두 C++에서 사용할 수 있다. C++에서 C 스타일 함수를 사용할 때는 `<cstdio>`와 `std::printf()`, `std::scanf()` 형식으로 작성할 수도 있다

# 7. 공백을 포함한 한 줄 입력

## 7.1 `>>`와 한 줄 입력의 차이

다음처럼 `>>`로 `std::string`을 입력받으면, 기본적으로 앞쪽 공백을 건너뛴 뒤 **다음 공백 문자 전까지** 읽는다

```Cpp
std::string name;
std::cin >> name;
```

입력:
```
Choi Sunhyeok
```

저장되는 내용:
```
Choi
```

이름이나 문장처럼 공백을 포함한 내용을 읽으려면 한 줄 입력 기능을 사용할 수 있다


## 7.2 문자 배열 입력: `std::cin.getline()`

> [!NOTE] `std::cin.getline()`  
> 입력에서 공백을 포함한 한 줄을 읽어 문자 배열에 저장하는 함수이다. 기본적으로 줄바꿈을 입력 종료 구분자로 사용한다

실제 호출 문법은 `cin::getline()`이 아니라 **`std::cin.getline()`이다**

```Cpp
std::cin.getline(문자배열, 저장가능한_크기);
```

| 인수      | 의미                      |
| ------- | ----------------------- |
| 첫 번째 인수 | 입력 내용을 저장할 문자 배열의 시작 주소 |
| 두 번째 인수 | 종료용 널 문자를 포함한 저장 공간의 크기 |

```Cpp
char name[20];
std::cin.getline(name, 20);
```

- 입력 내용은 최대 **19개의 `char` 원소**까지 저장한다
- 저장한 내용 뒤에 종료용 널 문자 `'\0'`를 붙인다
- 줄바꿈을 만나면 이를 입력 스트림에서 꺼내지만 배열에는 저장하지 않는다
- 두 번째 인수로 실제 배열 크기보다 큰 값을 전달하면 안 된다

입력이 다음과 같다면:
```
Choi
```

배열에 저장된 문자열은 다음과 같다.
```
Choi
```

> [!NOTE] 바이트 수와 글자 수  
> `char name[20]`에는 입력 내용 19바이트와 종료용 널 문자 1바이트를 저장할 수 있다. UTF-8 한글처럼 한 글자가 여러 바이트로 표현되면, 화면에 보이는 글자 19개를 저장할 수 있다는 뜻은 아니다


## 7.3 이름과 디저트 입력 예시

```Cpp
#include <iostream>

int main() {
    const int ArSize = 20;

    char name[ArSize];
    char dessert[ArSize];

    std::cout << "Enter your name:\n";
    if (!std::cin.getline(name, ArSize)) {
        return 1;
    }

    std::cout << "Enter your favorite dessert:\n";
    if (!std::cin.getline(dessert, ArSize)) {
        return 1;
    }

    std::cout << "I have some delicious " << dessert;
    std::cout << " for you, " << name << ".\n";

    return 0;
}
```

입력 예시:
```
Choi
ice cream
```

마지막 출력:
```
I have some delicious ice cream for you, Choi.
```

위 예시는 입력에 실패하면 종료한다. 계속 입력받으려면 실패 원인에 맞는 복구 처리가 필요하다


## 7.4 입력 길이 제한과 실패 상태

크기가 20인 배열에는 입력 내용 19바이트와 종료용 널 문자 1바이트가 들어갈 수 있다. 한 줄의 내용이 저장 한도를 초과하면 다음 상황이 발생한다
- 입력 스트림에 읽지 않은 문자가 남는다
- 스트림에 실패 상태인 **`failbit`가** 설정된다
- 이후 입력을 계속하려면 실패 상태와 남은 입력을 처리해야 한다

단, **19바이트를 저장한 직후 다음 입력이 줄바꿈이라면**, 줄바꿈을 소비하고 정상적으로 완료될 수 있다. 배열의 사용 가능한 공간을 채웠다는 사실만으로 무조건 실패하는 것은 아니다

### 7.4.1 길이 초과 후 현재 줄 버리기
입력 길이 초과로 실패했고 현재 줄의 나머지를 버린 뒤 다음 입력을 받으려면 다음 처리를 사용할 수 있다

```Cpp
std::cin.clear();

std::cin.ignore(
    std::numeric_limits<std::streamsize>::max(),
    '\n'
);
```
- `clear()`: 스트림의 오류 상태를 해제한다
- `ignore()`: 남은 입력을 줄바꿈까지 읽어 버린다
- `std::numeric_limits`를 사용하려면 `<limits>` 헤더가 필요하다

이 처리는 **길이 초과를 복구하려는 상황**에 해당한다. 입력 종료나 다른 오류도 모두 같은 방식으로 해결되는 것은 아니다


## 7.5 `std::string` 입력: `std::getline()`

문자 배열 대신 `std::string`에 한 줄을 저장하려면 다음 함수를 사용한다

```Cpp
#include <iostream>
#include <string>

int main() {
    std::string name;

    if (std::getline(std::cin, name)) {
        std::cout << name << '\n';
    }

    return 0;
}
```
- 공백을 포함한 한 줄을 읽는다
- 기본 구분자인 줄바꿈은 입력에서 소비하지만 문자열에 저장하지 않는다
- 문자열 객체가 저장 공간을 관리하므로 배열 크기를 직접 지정하지 않는다


## 7.6 두 `getline` 방식의 비교

|구분|문자 배열에 입력|`std::string`에 입력|
|---|---|---|
|호출|`std::cin.getline(name, size)`|`std::getline(std::cin, name)`|
|저장 대상|`char` 배열|`std::string`|
|함수 형태|입력 스트림의 멤버 함수|별도의 함수|
|크기 관리|저장 공간의 크기를 직접 지정|문자열 객체가 저장 공간 관리|
|공백 포함 입력|가능|가능|
|기본 종료 구분자|줄바꿈|줄바꿈|


## 7.7 `>>` 이후 남은 줄바꿈 처리

다음과 같이 숫자를 읽은 뒤 바로 한 줄 입력을 수행하면 문제가 생길 수 있다

```Cpp
int num;
std::string name;

std::cin >> num;
std::getline(std::cin, name);
```

사용자가 정수 뒤에 Enter를 입력했다면, `>>`가 정수만 읽고 줄바꿈을 남길 수 있다. 뒤의 `std::getline()`은 남은 줄바꿈을 즉시 만나므로 **빈 문자열을 읽을 수 있다**

### 7.7.1 현재 줄의 나머지를 버리고 다음 줄 읽기
숫자 입력에 성공한 뒤, 현재 줄의 나머지를 버리고 다음 줄을 읽으려면 다음처럼 작성한다

```Cpp
#include <iostream>
#include <limits>
#include <string>

int main() {
    int num;
    std::string name;

    if (!(std::cin >> num)) {
        return 1;
    }

    std::cin.ignore(
        std::numeric_limits<std::streamsize>::max(),
        '\n'
    );

    if (!std::getline(std::cin, name)) {
        return 1;
    }

    std::cout << "num: " << num << '\n';
    std::cout << "name: " << name << '\n';

    return 0;
}
```

입력:
```
20
Choi 
```

출력:
```
num: 20
name: Choi 
```
