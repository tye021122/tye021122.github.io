# 1. 음함수 미분법

> [!NOTE] 음함수
> 관계식 $F(x,y)=0$을 만족하도록 **암묵적으로 정의되는 함수 $y=f(x)$**를 음함수라고 한다. 하나의 관계식이 전체 구간에서 하나의 함수만을 정하는 것은 아니며, 여러 함수 가지를 나타낼 수도 있다
>
> 예를 들어 $x^2+y^2=25$는 $y=\sqrt{25-x^2}$와 $y=-\sqrt{25-x^2}$의 두 가지로 나누어 나타낼 수 있다

**음함수 미분법의 절차는 다음과 같다**
1. 방정식의 양변을 $x$에 대해 미분한다
2. 미분해서 얻은 방정식을 $\dfrac{dy}{dx}$에 대해 푼다

주어진 방정식이 $y$를 $x$에 대한 **미분 가능한 함수로 암묵적으로 정의한다**고 가정한다

> [!TIP] 연쇄법칙과 분모 조건
> $y$도 $x$의 함수이므로, 예를 들어 $n$이 양의 정수일 때 $\dfrac{d}{dx}(y^n)=ny^{n-1}y'$이다. $y$에 관한 식을 미분할 때는 연쇄법칙에 따라 $y'$를 곱한다.
> $y'$를 구하면서 어떤 식으로 나누었다면, 그 식이 0이 아닌 곳에서 결과를 적용한다.

# 2. 선형 근사와 미분량
## 2.1 선형 근사

> [!NOTE] 선형 근사
> 함수 $f$가 $a$에서 미분 가능하면, $x$가 $a$에 가까울 때 곡선 $y=f(x)$를 점 $(a,f(a))$에서의 **접선으로 근사**할 수 있다

이 접선은 점 $(a,f(a))$를 지나고 기울기가 $f'(a)$이므로, 방정식은 다음과 같다.
$$y=f(a)+f'(a)(x-a)$$

> [!NOTE] 선형화
> 접선을 나타내는 함수 $L(x)$를 **$a$에서의 함수 $f$의 선형화**라고 한다

$L(x)=f(a)+f'(a)(x-a)$
- $f(a)$: 기준점에서의 함수값
- $f'(a)$: 기준점에서의 접선 기울기
- $x-a$: 기준점으로부터의 가로 변화량
- $f'(a)(x-a)$: 접선을 따라 예상한 세로 변화량

**선형 근사 또는 접선 근사**
- 실제 함수값을 접선 위의 값으로 근사하는 것을 **선형 근사** 또는 **접선 근사**라고 한다

<figure> <img src="Pasted image 20260921171514.png" width="300"> <figcaption>그림 1. 선형 근사 그래프</figcaption> </figure>

$f(x)\approx L(x)=f(a)+f'(a)(x-a)$

그림에서 파란색 곡선은 $y=f(x)$, 빨간색 접선은 $y=L(x)$이다. 두 그래프는 접점 근처에서 가까우므로, $x$가 $a$에 가까울 때 접선을 이용해 함수값을 근사할 수 있다

### 2.1.1 과대근사와 과소근사
>[!NOTE] 과대근사와 과소근사  
>선형 근사에서 근삿값 $L(x)$가 실제 함수값 $f(x)$보다 크면 **과대근사(overestimate)**, 작으면 **과소근사(underestimate)**라고 한다

**이계도함수를 이용한 판단**
- 기준점 $a$와 근사하려는 점 $x$를 포함하는 구간에서 이계도함수의 부호를 확인한다

|해당 구간의 조건|그래프의 굽은 방향|선형 근사의 결과|
|---|---|---|
|$f''(x)<0$|위로 볼록, $\cap$, concave down|접선이 곡선 위에 있으므로 과대근사|
|$f''(x)>0$|아래로 볼록, $\cup$, concave up|접선이 곡선 아래에 있으므로 과소근사|

기준점에서는 $L(a) = f(a)$이므로 오차가 0이다

>[!TIP] 판단할 때 주의할 점  
>$f'(x)$는 함수의 증가·감소를, $f''(x)$는 그래프의 굽은 방향을 나타낸다. **과대·과소근사는 접선과 곡선의 위치 관계로 판단한다.** 이계도함수의 부호가 구간에서 바뀌는 경우에는 위 표를 그대로 적용하지 말고 $L(x)-f(x)$의 부호를 확인한다

### 2.1.2 선형 근사의 오차
> [!NOTE] 선형 근사의 오차  
> 선형 근사의 오차의 크기는 실제 함수값과 근삿값의 차이의 절댓값이다
> 
> $E(x)=|f(x)-L(x)|$

허용 오차가 $\varepsilon>0$이고, 오차가 이보다 작아야 한다면,

$$|f(x)-L(x)|<\varepsilon$$

이를 다음과 같이 바꾸어 $x$의 범위를 구할 수 있다
$$f(x)-\varepsilon<L(x) < f(x) + \varepsilon$$
그래프에서는 **접선 $y=L(x)$가 두 곡선 $y=f(x) - \varepsilon$와 $y=f(x)+\varepsilon$ 사이에 놓이는 범위**를 뜻한다

부등식을 풀 때는 함수의 정의역을 확인하고, 양변을 제곱하는 경우 양변의 부호를 먼저 확인한다. 오차가 $\varepsilon$과 같은 경우까지 포함하는 조건이라면 $\le$를 사용한다

## 2.2 미분량

> [!NOTE] 미분량
> $y=f(x)$가 미분 가능한 함수라고 하자. **미분량 $dx$는** 독립변수이며, 임의의 실수로 정할 수 있다. **미분량 $dy$는** 다음과 같이 정의한다. 
> 
> $$dy=f'(x)dx$$
> 
> 따라서 $dy$는 $x$와 $dx$의 값에 따라 결정되는 종속변수이다

$dy$는 현재 위치에서의 **접선 기울기 $f'(x)$에 가로 변화량 $dx$를** 곱한 값이다
$$접선의 세로 변화량=접선의 기울기×가로 변화량$$
- $dx$: 독립적으로 정하는 가로 변화량
- $f'(x)$: 기준점에서의 접선 기울기
- $dy$: 해당 가로 변화량에 대한 접선의 세로 변화량

$dx$ 자체는 임의의 실수로 정할 수 있다. 다만, 미분량을 이용하여 **실제 함수의 변화량을 근사할 때는 $|dx|$가 충분히 작아야 좋은 근사를 기대할 수 있다**

### 2.2.1 실제 변화량 $\Delta y$와 미분량 $dy$

<figure> <img src="Pasted image 20260921171645.png" width="300"> <figcaption>그림 2. 변화량 표시</figcaption> </figure>

함수의 그래프 위에 두 점
$$ P=(x,f(x)), Q=(x+\Delta x,f(x+\Delta x))$$
를 잡고, $dx= \Delta x$로 둔다. 이때 함수의 **실제 변화량**은 다음과 같다
$$\Delta y = f(x + \Delta x)-f(x)$$
이는 **곡선을 따라 이동했을 때 함수값이 실제로 증가하거나 감소한 양**이다. 한편, 점 $P$에서의 접선 기울기는 $f'(x)$이므로, 같은 가로 변화량에 대한 **접선의 세로 변화량**은 다음과 같다
$$dy=f'(x)dx$$
이는 **접선을 따라 이동했을 때 높이가 증가하거나 감소한 양**이다

| 구분       | 실제 변화량 $\Delta y$    | 미분량 $dy$            |
| -------- | -------------------- | ------------------- |
| 기준       | 함수의 **곡선**           | 현재 점에서의 **접선**      |
| 의미       | 곡선이 실제로 올라가거나 내려간 양  | 접선이 올라가거나 내려간 양     |
| 공식       | $f(x+\Delta x)-f(x)$ | $f'(x)\,dx$         |
| 그림에서의 구간 | $S$에서 $Q$까지의 세로 변화량  | $S$에서 $R$까지의 세로 변화량 |

여기서 $S$는 $P$와 높이가 같고 $Q$ 바로 아래에 있는 점이며, $R$은 $Q$와 같은 가로 좌표에 있는 접선 위의 점이다. 세로 변화량은 위쪽이면 양수, 아래쪽이면 음수이다

>[!TIP] $dy$와 $\Delta y$ 구별하기
>**$\Delta y$는 곡선에서의 실제 변화량이고, $dy$는 접선으로 계산한 변화량이다.** 일반적으로 두 값이 정확히 같지는 않다

### 2.2.2 미분량을 이용한 근사
기준점 근처에서는 곡선과 접선이 가까우므로, $|\Delta x|$가 충분히 작으면 실제 변화량을 미분량으로 근사할 수 있다
$$\Delta y \approx dy$$
즉,
$$f(x+\Delta x)-f(x) \approx f'(x)\Delta x$$
양변에 $f(x)$를 더하면,
$$f(x+\Delta x)\approx f(x)+f'(x)\Delta x$$
를 얻는다

이는 **새로운 함수값을 '기존 함수값 + 접선으로 계산한 변화량'으로 근사한다**는 뜻이다

### 2.2.3 선형 근사와 미분량의 관계
기준점을 $a$, 근사하려는 가로 좌표를 $x$라고 하자. $dx=x-a$로 두면 $x=a+dx$이다. 기준점 $a$에서의 미분량은 $dy=f'(a)dx$ 이므로 선형 근사 공식은 다음과 같이 표현할 수 있다
$$
\begin{align*}
f(x) &\approx f(a)+f'(a)(x-a) \\
&= f(a)+f'(a)dx \\
&=f(a)+dy
\end{align*}
$$
**따라서 $f(a+dx) \approx f(a)+dy$이다**

| 표현 방식       | 공식                            |
| ----------- | ----------------------------- |
| 선형 근사       | $f(x)\approx f(a)+f'(a)(x-a)$ |
| 미분량을 이용한 표현 | $f(a+dx)\approx f(a)+dy$      |
| 두 표현의 연결    | $dx=x-a,\quad dy=f'(a)dx$     |

>[!NOTE] 기준점 확인  
>기준점이 $x$이면 $dy=f'(x)dx$, 기준점이 $a$이면 $dy=f'(a)dx$이다. 두 식은 같은 정의이며, **어느 점에서의 변화량을 계산하는지**에 따라 표기가 달라진다

### 2.2.4 상대오차와 백분율 오차
> [!NOTE] 상대오차
> 상대오차는 오차의 크기를 기준이 되는 값의 크기로 나눈 값이다. 값 자체의 크기에 비해 오차가 얼마나 큰지를 나타낸다

부피 $V>0$에 실제 오차 $\Delta V$가 있을 때, 상대오차의 크기는 다음과 같다
$$상대오차=\dfrac{|\Delta V|}{V}$$
실제 오차를 직접 계산하기 어려우면 미분량을 이용하여, $\Delta V\approx dV$로 근사할 수 있으므로 아래 식이 된다
$$상대오차=\dfrac{|\Delta V|}{V}\approx\dfrac{|dV|}{V}$$
$\Delta V/V$는 부호를 포함한 상대적인 변화 또는 오차이고, $|\Delta V|/V$는 상대오차의 크기이다. **오차의 크기를 구할 때는 절댓값을 사용한다**

상대오차에 100%를 곱하면 백분율 오차가 된다. 상대오차는 같은 단위끼리 나누므로 **단위가 없다**

#### 측정 오차에 적용하는 방법
부피가 측정값 $x$의 함수 $V=V(x)$로 주어지고, $x$의 작은 측정 오차를 $dx$로 두면 $dV = V'(x)dx$이므로
$$부피의 상대오차 \approx \dfrac{|V'(x)dx|}{V(x)}$$
로 계산한다. 위 구의 예제에서는 $V=V(21)$, 즉 측정 반지름으로 계산한 부피를 기준으로 삼는다. 따라서 상대오차의 최대 추정값은
$$\frac{|dV|_{\max}}{V(21)}=\frac{4\pi(21)^2(0.05)}{\frac43\pi(21)^3}=\frac{3(0.05)}{21}=\frac1{140}$$
이며, 백분율 오차는 약 $0.714\%$이다.

>[!TIP] 두 종류의 오차 구별하기  
>**측정 오차를 미분량으로 추정한 값**은 $|dV|$이고, **그 근사 자체의 오차**는 $|\Delta V-dV|$이다.  
이 슬라이드의 $\dfrac{dV}{V}$는 측정 오차가 부피에 미치는 영향을 추정할 때 사용하는 식이다
